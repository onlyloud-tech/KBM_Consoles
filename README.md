# KnoxBox Media: Consoles

KnoxBox Media: Consoles adds playable Game Boy, Game Boy Color, NES, and Doom cartridges to Project Zomboid Build 42. Game Boy titles use a handheld; NES and Doom play through a console connected to a television, including a 3D screen in Viewpoint.

The mod requires KnoxBox Media Framework (`KBM_Core`) and ZombieBuddy 2.3.4 or later. Viewpoint is optional for the 3D screen. The Workshop release includes selected homebrew games and Doom-engine data; players can also use their own Game Boy and Game Boy Color ROMs.
