# KnoxBox Consoles homebrew notices

This mod distributes the GB/GBC homebrew titles listed below. Their original licenses, attribution notices and corresponding-source archives are under this mod's LICENSES/Homebrew/. CoffeeGB and the shared Java libraries are provided by the required KnoxBox Media Framework and documented there. The bundled NES emulator uses [HalfNES](https://github.com/andrew-hoffman/halfnes) under GPL-3.0; readable source for the shipped classes is in `third-party/HalfNES/` in this source repository.

- Big2Small: `Homebrew/big2small/source/corresponding-source.tar.gz`, author release v1.0.0, archive SHA-256 `e3f6c1968faeb0168ac5b1227513d19249891e036902d5756b757e4c0977993d`.
- Geometrix: `Homebrew/geometrix/source/corresponding-source.tar.gz`, author v1.0.0 source containing the matching ROM, archive SHA-256 `40fede55ece5f68ab39b2e2c45e419bb329e1b36c794b62ea270d7d505972b70`.
- Bit Bang: `Homebrew/bit_bang/source/game-source.tar.gz` and `hUGEDriver-source.tar.gz`. The game rebuilt byte for byte with GBDK 4.3.0. hUGEDriver revision `0f10d494b1415c868abb5e8ca37f32a477ec111c` rebuilt to the embedded object (SHA-256 `730a3eb19dbf08b0e58de3d5b303acceecfa1e2ed9b94bdc5415a00d8427e1b0`) using RGBDS 0.5.2 and `tools/rgb2sdas.py -b 0`.

The ROMs are redistributed unmodified. RGBDS, GBDK and host build tools are external and are not included.
