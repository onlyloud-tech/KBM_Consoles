# Doom runtime and Freedoom notices

The KnoxBox Doom cartridge runs through a minimized bridge based on MochaDOOM. It is a separate engine presented through the same television UI as the NES console; `freedoom1.wad` is not an NES ROM.

- Engine/runtime: GPL-3.0-or-later. See `MochaDOOM-GPL-3.0.md` and `MochaDOOM-corresponding-source.tar.gz`.
- Game data: Freedoom 0.13.0, BSD-3-Clause. See `Freedoom-0.13.0/`.
- Freedoom Phase 1 SHA-256: `7323BCC168C5A45FF10749B339960E98314740A734C30D4B9F3337001F9E703D`.
- Official release: https://github.com/freedoom/freedoom/releases/tag/v0.13.0

KnoxBox distributes the Freedoom WAD unmodified. Its cartridge metadata, model skin, Lua host, and Java bridge packaging are separate integration work.
